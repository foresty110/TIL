# 모니터링 기술 별 역할 
Micrometer   애플리케이션의 성능 데이터를 코드 수정 없이 다양한 모니터링 시스템(Prometheus, Datadog 등)에 쉽게 연동할 수 있도록 도와주는 자바 표준 메트릭 수집 라이브러리
Prometheus   애플리케이션이 뱉어내는 메트릭을 주기적으로 수집하고 저장하는 오픈소스 모니터링 시스템
              (*메트릭: 자바 코드나 시스템 안에서 일어나는 일들을 숫자로 측정해 기록한 실시간 데이터) 
Grafana      저장된 데이터를 그래프로 시각화하는 도구

# 메트릭 대표적인 종류

1. Counter: 값이 계속 증가하기만하는 경우에 사용, 이 자체로는 "현재 상태"를 알 수 없기 때문에, rate() 같은 함수와 조합해서 "초당 처리량(속도)"을 계산할 때 사용
ex) 지금까지 발생한 총 HTTP 요청 횟수

2. Gauge: 현재 순간의 실시간 상태 표현이 필요할때 사용
ex) 현재 활성 DB 커넥션 수

# PromQL
Prometheus에서 데이터를 조회하고 계산하는 언어 
| 함수 | 의미 | 예시 |
| :--- | :--- | :--- |
| rate() |       초당 평균 증가량     |    초당 체결 수신량 | 
| increase() |   일정 시간 동안 증가량 |  최근 5분 실패 건수 | 
| sum()  |       전체 합계          |      전체 서버 처리량 | 
| sum by()  |    특정 항목별 합계     |     파티션별 처리량 | 

# Grafana 대시보드 설정 파일

| 속성 | 의미 |
| :--- | :--- |
| **title** | 대시보드 또는 그래프 제목 |
| **uid** | 대시보드 고유 식별자 |
| **datasource** | 데이터를 가져올 출처 |
| **panels** | 대시보드에 표시할 그래프 목록 |
| **targets** | 그래프가 실행할 데이터 조회 쿼리 |
| **expr** | Prometheus 조회 쿼리 (PromQL) |
| **legendFormat** | 그래프 범례 이름 |
| **gridPos** | 그래프의 위치와 크기 |
| **type** | 그래프 표현 방식 |
| **refresh** | 화면 갱신 주기 |
| **time** | 기본 조회 시간 범위 |
