### 프로젝트 요구사항   
대용량 주식 체결 데이터를 실시간으로 수집한다. 사용자가 설정한 체결가에 도달했다면 알림을 발송한다. 

### 제약 조건: 
- 대용량 데이터 수집으로 인한 처리 병목이 발생해선 안된다. 
- 체결 데이터가 유실되어선 안된다. 이는 서비스 신뢰를 잃게 만들기 때문이다. 

### 예상 문제
- 현재 구현 상태
  - WebSocket으로 수신한 체결 데이터를 Java 애플리케이션에서 일정 시간 동안 종목별 최고가·최저가로 집계한 후 Kafka로 발행하는 구조.
  - 이때 집계 상태를 애플리케이션 메모리에서 관리
- 가설: 처리 도중 서버 장애가 발생하면 미발행 데이터가 유실될 가능성이 있다.

### 검증 방법 
1. 단계별 데이터 추적 구조를 만든다.
  1. 수신 이벤트 건수
  2. 집계 반영 건수
  3. kafka 발행 건수
2. 테스트 데이터 및 시나리오를 설계한다.
3. 정상 상황에서 데이터가 정확하게 처리되는지 확인한다.
4. 집계 도중 애플리케이션을 강제 종료하여 서버 장애 상황을 만든다.
5. 서버를 다시 재시작한 후 정상 상황과 결과를 비교한다.
