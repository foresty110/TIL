# Spark Structured Streaming
- Micro-batch:  들어온 스트리밍 데이터를 작은 배치 단위로 나누어 처리하는 방식
공식 가이드에서 Micro-batch는 약 100ms 수준까지의 지연 시간을 목표로 한다고 설명, 
100ms마다 끊어서 처리하다 보면, 파이프라인 전체를 거치면서 지연 시간이 계속해서 늘어난다. -> 시세를 놓친다. 
데이터 처리 자체가 빠르더라도 배치를 구성하고 실행하는 데 드는 시간이 추가될
